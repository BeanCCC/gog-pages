本站是仅供站点所有者本人使用的轻量工具站点，为「workbuddy」这个个人自动化工具提供 公开的说明页面与法律条款页面。它不面向公众提供任何服务，也不注册用户。

This site exists solely to host the public information pages for workbuddy, a single-user personal automation tool. It offers no public service and has no user registration.

这个工具做什么

workbuddy 是本人在自己电脑上运行的命令行工具，用于把本地的个人待办事项整理成日程事件， 并写入本人自己的 Google 日历。它只读取和写入本人授权范围内的 Google 日历数据， 不涉及任何他人的数据。

  • 运行环境：本人个人电脑，本地运行，无服务器后端
  • 数据范围：仅本人 Google 账号下的日历事件
  • 使用方式：仅本人使用，不对外提供

数据用途说明

本工具通过 Google Calendar API 读取与创建本人日历中的事件。所获取的数据仅用于在本人设备上 生成和更新个人日程提醒，不收集、不出售、不共享、不转让给任何第三方，也不用于广告或 用户画像。详情见 隐私政策。

Google API 权限说明

本工具申请的 Google OAuth 权限范围（scope）为 https://www.googleapis.com/auth/calendar，即对本账号日历的读写权限。 该权限仅授予本人账号，授权令牌保存在本人电脑的本地凭据管理器中，可随时在 Google 账号权限页 撤销。
